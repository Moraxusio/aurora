# Aurora 4.0.1-public-preview1

> 类型：版本说明 | 状态：候选 | 维护：项目维护者 | 更新：2026-11-21
> 适用：Windows x64 单 EXE、Linux amd64 单 ELF；GitHub 预发布候选

**这是 4.0 公开预览，不是正式升级包。** 不替换现有 3.x 正式版安装、Profile 或 Linux systemd 服务。可用独立工作区体验紧凑资源管理器、文件操作和受保护的本地状态。

- **Windows x64：** 单 EXE 内嵌 Aurora 签名的运行包，启动前验签并验证缓存。使用 `%LOCALAPPDATA%\Aurora4PublicPreviewState\Aurora3`，不会读取或修改生产 Profile，也不会自动连接已保存服务器。Windows 外层未做 Authenticode 签名，可能显示「未知发布者」。
- **Linux amd64：** 单 ELF 单独提供，清单签名属于 `preview` 通道，不是 3.x 的 `stable` 升级产物。只支持手工启动具名、加密的隔离回环实例，不支持系统服务安装、升级或卸载。不开放远程终端、代理、端口转发和 systemd 管理；Windows 预览也不提供远程 agent 安装或升级。
- **可选迁移验收：** 只克隆已停止的旧状态，不在原目录转换。未识别的旧数据、缺密钥、损坏的身份或已存在的目标拒绝覆盖。保留原件不等于把新写入逆向迁回旧版。

使用前核对随附的 `SHA256SUMS.txt`。Linux 将 ELF 与 `manifest.json`、`manifest.sig` 放到同一个目录时，可信源码构建的 `aurora3-release verify --channel preview --dir <目录>` 可复验签名、版本及文件 SHA-256。启动、凭据与克隆步骤见 [隔离验收指南](../development/protected-state-preview.md)；生产迁移范围见 [4.0 升级清单](../development/roadmap-4-0.md)。
