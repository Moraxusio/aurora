# Aurora 3.25.0-gui-preview13

> 类型：版本说明 | 状态：候选 | 维护：客户端维护者 | 更新：2026-11-20
> 适用：Windows x64 桌面验收

- 一个搜索入口、同一个输入框。文件名、文件内容和命令在浮层内切换；桌面左侧不再有重复搜索入口，侧栏只承担内容结果与选项。各入口快捷键保留，窄窗保留触控搜索。
- 终端默认全宽显示输出。会话名就是切换器，会话管理按需出现；新建、更多操作、隐藏各有一个入口。关闭视图和结束会话明确区分。
- 翻到历史后出现「回到最新输出」按钮，不因新输出重置阅读位置。隐藏不重建终端实例或连接。

解压后通过 `启动验收版.cmd` 在独立配置中验证，步骤见 [开始使用](../guides/getting-started.md)。随包 agent 已签名，Windows 客户端不是 Authenticode 签名包。
