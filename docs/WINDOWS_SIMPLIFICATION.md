# Windows：侧栏跟手与界面减法

在 Astra 首轮验收基础上，针对用户反馈继续调整。Windows 独立验收完成，用户已授权作为 3.18.0 编译打包发布；最终发布状态见 PLAN。

## 侧栏跟手

旧回调使用“上次布局时的宽度 + 本次事件增量”。绘制虽然按帧合并，但同一帧内多个鼠标事件共享旧宽度，先前的增量被覆盖；帧耗时合格并不等于跟手。拖动识别还存在起步阈值。

现在所有工作台分隔线统一采用：

- 按下时记录实际显示尺寸、全局指针原点与 UI 坐标比例。
- 每个事件用**起始尺寸 + 总位移**计算目标，不依赖上一帧的布局值，也不使用会跟着分隔线移动的局部原点。
- 按帧绘制最新结果；第一像素立即响应，同帧高频事件不丢失。拖出尺寸边界再回拖仍以原指针位置为准。
- 左文件栏、右 AI、底部终端、文档分组和纵向标签栏使用同一机制。保留双击复位、尺寸约束、按帧几何通知和延迟持久化。

## 奥卡姆剃刀：一个区域，一层常驻工具

- **文件**：工作区选择、新建文件、刷新和选项合为一条 36px 工具栏。目录树根节点改为普通单行，完整路径通过悬停查看；选中文件不再额外插入路径栏目。后台项目树保留最后尺寸。
- **文档**：标签下直接进入正文，完整路径仍在标签提示中，去掉重复路径条。
- **AI**：保留必要的会话标题和固定消息导航；工作目录/选项并入导航行。正文下只有输入及一行模型、上下文指示、Build/Plan、Ask/Auto、附件、发送控件。详细实际模型/累计用量按需展开；推理强度放进完整模型提示和模型选择器。真实发送参数与权限模式不变。
- **历史**：在 AI 所在区域直接切换历史/对话，不再打开盖住编辑器的历史窗口。新建入口使用原标题栏按钮，取消重复的整行按钮；标题栏下直接搜索和浏览历史。原对话宿主、输入和流保留。
- **窗口**：中等宽度的文件侧栏直接与正文并排，取消遮罩抽屉。标题栏去掉与活动栏重复的终端/AI 按钮；齿轮单击直接打开设置。

日常导航采用同区域切换或单层菜单。涉及文件删除、覆盖、未保存内容的确认仍遵循原来的事务保护。

## 验证方法

`test/sidebar_resize_test.dart` 在 100% / 125% / 150% UI 缩放下，分别测试左右侧栏第一像素、同帧十次事件、反向拖动及越界返回，并逐帧检查分隔线位置。另验证无工作区业务广播、编辑器实例保留和文件树单工具栏。

原生 Profile 测试新增文件侧栏每帧四次移动，共 128 个事件，记录实际分隔线与指针偏差以及 build/raster 帧耗时。AI 历史回归验证无 Dialog、文档仍可见、返回后草稿与组件实例保持。最终结果与独立包信息见 PLAN/BUILD-INFO。
