### C2 补充：会话存储与边界

- 启动只保留索引元数据；正文按需加载，空闲缓存最多 8 会话／约 64 MiB 磁盘体积。读取及搜索克隆也离开全局锁，跨会话并行、同会话顺序落盘。
- 派生 index 增加 CRC32；缺失／损坏时重建。正文读取与搜索不改写或 fsync index，读取期间外部变化拒绝发布。
- 增量日志验证长度、CRC32、序号与消息范围；断尾另存证据，轮换检查点前也保留断尾。坏会话／孤立日志仍可见，并阻止未知引用的附件与快照 GC。
- 回退将正文检查点、空 journal 和恢复文件同批提交，并核对外部会话版本。会话与事务单文件统一 64 MiB；事务前后版本合计 256 MiB、最多 512 个目标。整批删除预先核验目标数量及体积，超额时指导先删除部分子会话。
- 恢复不确定状态通过线程安全的共享 gate 阻止后续写入；恢复冲突同时保留原始错误类型。超过旧 32 MiB 的会话回退／删除及 172 会话树的超额删除纳入边界回归。
- MCP 会话／协议版本并发访问已加锁；覆盖真实 stdio 子进程、取消回收、HTTP session／SSE、分页循环、超额响应及兼容标识。
- 共享输出预算耗尽后辅助请求也拒绝上游访问；辅助请求不扣工具步骤，缺失 usage 与过大流式 delta 有回归。
