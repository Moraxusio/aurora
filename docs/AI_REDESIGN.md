## 交互约定

1. 设置分为「连接」「模型」「工具与权限」「对话」。网络收进连接页；每页独立滚动，导航和保存固定。
2. 浏览、添加、编辑连接不隐式切换默认提供商。默认连接在「对话默认值」中明确选择。
3. 普通配置使用草稿，保存后生效，取消丢弃；离开时检查未保存修改。登录/退出凭据即时加密保存，并明确标注。
4. 目录接口可达、已存凭据、订阅推荐目录、模型实际可调用是不同状态。拉取目录不声称完成模型调用验证。
5. 模型选择器先选择再「应用」，只改变当前会话的后续输入；关闭取消。思考强度可自由填写，实际运行身份与下一次选择分别显示。
6. 权限规则有序，最后匹配生效；项目规则绑定服务器 ID 与项目 ID，只有该项目目录内使用。规则支持编辑、上下移动、删除。
   规则编辑表单参与未保存检测，点击「保存设置」会同时加入/更新正在填写的规则。
7. 审批区显示操作摘要、授权范围和详情入口。网络失败保持问题与错误，提交中禁用按钮，成功才清除。
8. 窄侧栏使用两层输入控制：独立模型行，操作/附件/发送行；短窗收纳次要选项，保留发送与停止。
9. Enter 和发送按钮经过同一命令分发；中文输入法合成时 Enter 不发送。
10. 补充在下一次模型步骤前加入；排队等当前任务不再请求工具后逐条启动，模型与权限随对应输入生效。
11. 队列窗口跟随任务状态实时更新。停止后输入标为「已保留」，重新发送显式使用当前会话选择；开始其他任务不会自动重新投递保留项。
12. 先持久化用户输入，再确认接收和广播投递；保存失败回滚输入。待发送附件参与引用保活。

## 状态与恢复边界

- 普通设置、API Key、OAuth 凭据存入本机加密 profile。目录拉取成功只说明目录接口响应，不代表实际对话已通过。
- 会话界面的模型和思考强度选择由当前保活宿主管理，不写回全局默认。重开已运行的会话时可从 runtime 恢复提供商/模型；未发送的选择和会话思考强度尚不跨应用重启保存。
- 排队项持久化输入、附件引用、工作模式、权限和不含密钥的 runtime 标识。提供商凭据仅在已接收任务的内存中存在，重启后需要显式重新发送。
- 补充输入会在步骤边界合并；同一边界有多条补充时，最后一条的模型与权限用于下一步骤。排队输入逐条执行，各自使用接收时的选择。
- 运行时「本会话允许」可查看和撤销，在 agent 重启后清除。新会话使用设置默认；现有会话的选择不会因后台历史同步被重置。
- 队列管理和会话授权入口按 agent capability 启用；新排队语义要求本轮 agent。真实账号鉴权、订阅权限和上游限流须由账号实机验证。
