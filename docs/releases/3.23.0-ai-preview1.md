# 3.23.0-ai-preview1：AI 配置中心与快照修复

> 类型：版本说明 | 状态：候选 | 维护：AI 维护者 | 更新：2026-11-16
> 适用：Windows x64 客户端、Windows 本地 agent、Linux amd64 agent

## 使用

完整解压后运行 `aurora.exe`，使用现有本机加密配置。`启动验收版.cmd` 使用包内独立 `review-data`。本包是本地完整候选，同包双 agent 为 3.23.0；远程需升级 agent 后使用新配置能力。

## 本次变化

- AI 配置总览、直达项目设置；项目预算、快照、指令、技能、MCP 和模型价格都有表单，高级 JSON 保留同一草稿。
- 模型可覆盖上下文窗口、最大输出；连接支持高级请求头。标明配置范围、生效时机与继承关系。
- 预算可逐项取消限制，显示已用、预留、来源、辅助调用、下一步需求与费用；支持自动标题／压缩开关。
- 修复失败消息遗漏提供商信息和无响应错误将全部预留输出计作已用的问题。预算停止后可调整、压缩或继续原任务。
- 快照对照 OpenCode 的有效文件范围：使用真实 Git 忽略规则，排除嵌套未跟踪依赖，跳过大型新文件；可检查范围、调节上限及清理未引用对象。
- 修复 20000 文件固定阈值及重复内容被当成新增存储的问题。原有文件事务和回退冲突检查保留。
- OpenCode 兼容协议与身份请求头继续保留。
