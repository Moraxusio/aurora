# AI 协作

> 类型：使用指南 | 状态：生效 | 维护：AI 维护者 | 更新：2026-11-20
> 适用：3.25.0 GUI 候选及同版本 agent

## 页面与设置范围

AI 使用对话进行协作。有任务时可打开工作视图；AI 设置集中管理连接、人设、权限和默认值。对话菜单提供授权、用量、压缩与消息跳转；侧栏布局菜单提供展开、还原和隐藏。

| 入口 | 生效范围与保存方式 |
|---|---|
| 输入框 Persona 按钮 | 为当前对话选择人设；已有连接可继续使用兼容的默认值，无需先迁移才能打开旧会话 |
| 输入框执行策略按钮 | 管理当前对话的模式、权限、预算、子代理、自动压缩和快照；新对话继承默认配置 |
| AI 设置 → 权限与工具 | 保存通用工具开关和授权规则；同版本 agent 在进行中的对话内同步适用的权限改动 |
| AI 设置 → 对话与编排 | 设置新对话的默认策略、编排角色、运行时发送方式和阅读偏好 |

策略窗口取消不会应用修改；发送失败保留输入和附件。AI 设置页在宽窗使用侧边导航，窄窗使用页面下拉。

## 连接与 Persona

在 **连接与模型** 配置 API Key 网关或 ChatGPT 设备码订阅、网络出口和代理。连接可以拉取模型目录、手填 ID 或从目录生成 Persona；目录只代表发现／配置结果，不证明账号调用资格。

在 **智能体人设** 设置模型、上下文窗口、最大输出、思考格式／强度／预算、能力和权限。编排模式可独立选择负责拆解调度的指挥和处理子任务的乐手。

订阅路由不发送 `max_tokens`，输出由上游控制，Aurora 本地仍统计运行用量。连接页的高级请求头用于自定义网关，OpenCode 身份标识保持固定。OAuth 登录／退出立即加密保存。

## 设备码与网络

订阅连接点击“使用设备码登录”，在自己发起的浏览器登录页完成授权。默认设备码、交换与刷新走客户端本机出口，也可切换到当前 agent 出口后重试。

**模型请求始终由当前 agent 发出**，与授权出口分开。设备码阶段的 403 不能证明订阅无效；模型列表也不是资格探测。Windows 本机出口支持环境代理／手动系统代理，不解析 PAC-only 配置。

API Key 与 OAuth 凭据保存在客户端加密 Profile；本机刷新不把 refresh token 发给 agent。agent 不持久保存刷新令牌为长任务无限续期，过期后需回到客户端刷新／重试。订阅固定官方路由，不使用普通网关地址。

## 对话、工具和附件

新会话先选择项目目录，开始后目录固定。**补充指令**插入当前任务，共用它的运行策略与预算；**排队发送**在当前任务完成后开始，使用发送时固定的策略并建立独立预算。任务停止／agent 重启后保留待发送项，需明确重新发送。

**任务**页可查找子代理与 Shell、筛选进行中或需处理、打开对话／输出、停止子代理或所属任务。停止主任务会取消其在途子代理；单独停止一个子代理保留其它子代理，并把停止结果与子会话引用返回主代理。主对话、子会话与输出保留独立草稿／阅读位置。

待审批工具可查看命令／差异；多个子代理审批按 ID 排队，逐项批准或拒绝，重连恢复待处理项。提交失败保留当前请求供重试。“本会话允许”记住的范围可从对话菜单的“本会话授权”撤销。

默认 Enter 发送、Shift+Enter 换行，可在 **AI 设置 → 对话与编排** 改为 Ctrl/Cmd+Enter。IME 组合输入不会触发发送；新对话示例只填入草稿，不会发送。思考过程、工具错误详情和消息导航均可设置；Alt+↑/↓ 仍可跳转。

附件菜单可选本机／agent 文件、粘贴图片、附加当前未保存缓冲或选区。粘贴不会立即上传，发送才上传。`read` 可读取工作区图片／PDF 并交给支持的模型，历史保留不可变附件引用。附件复制到 agent 私有存储，普通文件和附件不是客户端加密 Profile。

工具能力包含文件读取与变更、`apply_patch`、搜索、Shell、结构化询问等。工具执行受权限与运行预算约束；每步结果持久化，重启后不盲目重放结果未知的副作用。OpenCode 兼容协议及请求标识保留。

## 修改建议

编辑器 AI 建议使用带版本的未保存缓冲、选区和诊断。审阅页逐块接受／拒绝、撤销、整批保存并运行验证任务；文件在预览后发生变化时使旧结果失效。`Alt+\` 请求行内续写，`Tab` 接受、`Esc` 拒绝。

已接受的未保存内容由文档恢复保护；尚未接受的建议和验证版本关联当前只在内存。验证任务的通过只对应记录中的文档版本。

## 指令、技能、MCP 与费用

3.25 候选不再提供独立的项目策略编辑页。运行参数优先在对话中编辑，agent 仍读取项目的 `.aurora/ai.json` 扩展配置。已接收的任务与排队项使用接收时的运行预算；即时权限更新不改写该预算。

项目指令、技能和 MCP 可继续通过扩展配置使用，连接在运行结束／取消时释放。不要把包含凭据的环境变量或授权请求头写入项目文件。

配置示例、共享预算、价格字段和快照清理见 [开发工具的扩展配置](development-tools.md)。金额预算需要当前模型价格；主任务、子任务和辅助请求共享预算。

## 代理协作与工具控制

- 主代理同时运行的子代理数可设 **1–16**，默认 1；可在当前对话的执行策略中覆盖。
- 单条任务的子代理总量默认 32，可设 **0–1000**，0 为不限。项目可禁用子代理，或只允许只读探索。
- **子代理始终不能继续创建子代理**；重新打开子会话仍受限制，只读探索身份也保留。主任务运行期间子会话由主任务调度，补充指令发送到主对话。
- 只有模型同一步连续提出的独立 subagent 调用并发，每批不超过并发上限；其它工具保持顺序。共同使用的工作目录并非分离工作树。
- 每步最多执行 **1–64** 次工具调用（默认 64）；连续相同工具／参数的确认阈值 **0–20**（默认 3，0 关闭检测）。
- Shell 默认及最大超时均为 **1–600 秒**（默认 120 / 600），默认不得大于最大；超出最大值的请求按最大值执行。

## 预算不足时怎样继续

**上下文窗口**是单次调用能容纳的输入量；**运行预算**是一次任务内多次请求的累计输入＋输出；**会话累计用量**跨多次任务。每一步重发的上下文都会再次计入运行预算，缓存 token 也包括在输入中，费用按缓存单价计算。

默认仍为 60 步、900 秒、500000 tokens、2 MiB 流式输出、不限制金额。五项预算均可设 **0 表示不限**；「长任务预设」为 200 步、7200 秒、5000000 tokens、8 MiB 输出。自动标题和自动压缩可分别关闭。金额由模型价格计算；无 usage 时使用观测内容估算，失败无响应时不再把预留输出当成已生成量，但上游实际计费仍可能未知。

关闭对话运行预算只取消运行限额，仍统计 token、时间、输出与费用，不取消上下文、工具、权限和存储约束。补充指令共用现有预算；需要独立预算时改为排队。自定义执行策略需要 agent 的 `ai.run.options` 能力。

运行摘要显示已用／上限；详情显示来源、步骤、辅助调用、预留、时间、输出和费用。预算不足会显示精确原因与下一步输入估算，并保留当时的提供商信息和已接收内容。可点击「调整预算」保存新设置，然后返回对话点击「继续任务（新预算）」；它会在原会话中发送继续指令并启动新预算，不自动重放旧工具。也可先手动压缩上下文。

## 快照与回退

可在对话执行策略开关「修改前创建文件快照」；文件、内容、存储、超时上限和额外忽略规则仍可由项目扩展配置管理。

快照范围对照 [OpenCode Snapshots](https://opencode.ai/docs/snapshots)（2026-11-16）：Git 项目读取真实索引，继承上级 `.gitignore`、仓库 `info/exclude` 和全局忽略；只捕获会话工作目录内的已跟踪文件及不超过 2 MiB 的未忽略新文件。嵌套依赖／构建目录只对未跟踪文件排除，符号链接／子模块目录不捕获。大型未跟踪文件会跳过，不使整个步骤失败。Aurora 额外支持显式选择的非 Git 目录，使用目录内忽略规则和依赖排除。

默认 200000 个有效文件、已跟踪单文件 8 MiB、单树 128 MiB、对象库 512 MiB、60 秒；均有表单说明和可调范围。相同内容由 Git 去重，不把完整工作树重复算成新增存储。关闭快照保留已有恢复点。快照失败给出设置入口；回退仍逐项校验当前文件并通过事务提交，不能回退命令的外部副作用或未覆盖文件。

## 会话与边界

会话列表先读索引，正文按需加载；日志损坏、外部变化及未知引用会被保留和报告。回退及整批删除受事务预算约束，大量子会话可先分批删除。

真实账号授权、订阅资格、识图与模型代码任务质量尚未完成本轮实测。协议夹具与包内 agent 冒烟不替代真实模型验证。完整限制见 [能力边界](../reference/compatibility.md)。
