# UI 验收版：少一点界面，多一点工作

这是 3.14.0 之后的客户端改造，用户已验收并授权纳入 **3.15.0**。不改变配置格式或凭据；旧 3.14.0 产物保持原样。下文“独立验收”记录的是先行预览包，正式 3.15.0 按统一版本流程重新构建并签名客户端和 agent。

## 设计取舍

参考主流 IDE 的信息层级与直接操纵方式，但不复制它们的资源或实现。以奥卡姆剃刀作为约束：

1. **不要求先学概念**：标签就是任务入口；分屏是摆放方式，不是另一个需要管理的对象。删除常驻“编辑组 N”、计数和每组重复的布局按钮。
2. **一个动作，一个反馈**：拖动只显示当前落点的一块预览，标签列表只画插入线；落下才修改布局。不会一开始就盖满五块指示区。
3. **低频能力按需出现**：默认活动栏只保留文件、搜索、Git、终端和 AI，其他工具收进“更多工具”；连接与设置归到一个入口。文件上传、隐藏文件、排序和大小统计在“文件选项”里，剪贴板粘贴有内容时才出现。
4. **让正文占主导**：连续、平整的工作台替代层层圆角面板；深浅色保持相同层级，强调色主要用于当前焦点。文件侧栏不重复显示“文件”和项目两个大标题；欢迎页改为直接的动作列表。
5. **细节可看，但不强迫看**：AI 默认一行实际模型与上下文概览；“模型与上下文详情”可展开下一次选择、完整上下文和累计用量。批准、错误、实时工作活动不因精简而隐藏。

## 怎么用

- 拖到标签**前半部/后半部**：插到前面/后面；长标签栏拖到边缘自动滚动，普通鼠标滚轮也能横移。
- 拖到正文边缘：预览并分屏；拖到另一视图中央：移入。只有放下才提交，取消保持原位；固定区域规则不变。
- 标签栏右侧 `…`：向右/向下分屏、放大当前视图、还原、合并、标签栏与布局及批量关闭。
- 标题栏“布局”：图形化选择单页、左右、上下、三列或四宫格，以及标签栏位置；宽度设置按需展开。
- `Ctrl+\` / `Ctrl+Shift+\` 分屏，`Ctrl+1–4` 切换视图，`Ctrl+Shift+Enter` 放大/还原；`Ctrl+Tab` / `Ctrl+W` 仍跟随当前视图。
- 侧栏与视图分隔条直接拖动，双击复位。现有文件布局、固定项和未保存缓冲的保护规则沿用。

## 卡顿修复与证据

确定性回归在同样的合成工作区检查“做了多少无关工作”，不把测试环境耗时当作真实帧率：

| 场景 | 修改前 | 修改后 |
|---|---:|---:|
| 30 个标签，24 次视口缩放，隐藏正文 `performLayout` 次数 | 696 | 0 |
| 240 次连续宽度更新，工作区业务通知次数 | 240 | 0 |
| 同一批 240 次更新的几何通知 | 混入上述业务通知 | 1 次按帧通知 |

- 隐藏正文保持最后一次约束，不再随着整个窗口尺寸反复排版；实例、缓冲和终端流仍保留。
- 高频宽度/比例更新走单独几何信号，保存时才捕获最终 JSON 快照；显式 flush、退出、项目切换和在途保存仍覆盖最后修改。
- 布局计算预建标签/归属索引，避免每个正文再线性查找所有标签；Shell 保留编辑区 widget，几何变化不重建无关侧栏与业务页。
- 拖动开始和移动只更新局部拖放状态。每个视图一个正文目标、每个标签栏一个目标；插入标记和边缘滚动独立绘制，不在每次悬停时序列化或写配置。

真实桌面长时间拖放、不同 DPI/刷新率、触摸设备和 Android 真机仍需要验收；没有宣称已经达到某个 FPS 或“比 VS Code 快几倍”。
