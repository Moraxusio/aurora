# Windows 工作台重构 · Astra 验收版

基线：3.17.0 / `16c4b84`。本轮重新设计 Windows 界面与热路径，独立验收完成，用户已授权作为 3.18.0 编译打包发布；最终发布状态见 PLAN。Android 暂缓。

首轮验收后，用户反馈侧栏拖宽不跟手、栏目堆叠过多。后续调整见 [侧栏跟手与界面减法](WINDOWS_SIMPLIFICATION.md)：改为指针总位移定位，合并文件工具栏、压平 AI 控件和原位历史；以下性能表保留为首轮记录。

## 视觉与结构

- 连续中性灰工作区、直角面板、1px 分隔线、蓝色焦点标记。35px 标题栏、48px 活动栏、36px 文档标签、23px 状态栏。支持深色、浅色和系统主题。
- 左上图标提供工作台菜单；`Ctrl+,` 打开可搜索设置页。精确输入、步进和滑块共用同一实时值。
- 文档、AI、终端独立保活。文件侧栏使用固定宿主，关闭/重开或变成抽屉时保留文件树。后台服务器及侧栏保留最后尺寸，避免随前台拖宽一起重排。

## 实时字号

旧实现中，终端 `TerminalStyle` 写死 14；设置每个滑块事件都通过 `AppState.update` 排队复制、加密和保存整份配置，写盘完成才通知 UI；通知又递增工作区 `viewRevision`，触发正文重建。AI 刷新时也反复复制整份 profile 来读取提供商。

新 `AppearanceController` 同步更新无凭据显示快照，已打开的文件、终端与 AI 在下一帧生效。连续事件合并，240ms 安静期后保存；滑块松手、精确输入提交和完全退出时 flush。只合并变更字段到最新配置；慢保存不回滚预览，失败保留待保存值并可重试。保存成功不广播工作区业务通知。

`Ctrl++` / `Ctrl+-` / `Ctrl+0` 调整或还原整个工作台逻辑尺寸。缩放宿主在 100% 时也保留，不通过重新创建页面缩放。

沿用 `editor.font_size`、`ai.chat_font_size`，新增可选 `editor.terminal_font_size`、`editor.ui_scale`。字号 9–28，UI 缩放 80–150%。现有配置直接读取，API Key/OAuth 不迁移、不重置。

## 鼠标与拖放

- 标签拖动排序、跨组移入；正文五向停靠标记：中央移入，上下左右分屏，也可拖到边缘直接放下。
- 边缘热区为视口 18%，限制为水平 36–110px、垂直 36–90px。角落按最近归一化边缘决策，修复靠近上边缘误选左侧。
- 悬停不改布局，松手事务提交，Escape 取消。保留项目代次、标签实例、布局 revision 检查和固定标签、异步关闭保护。
- 单击立即激活，不等待双击超时；双击标签放大/还原分组，中键关闭。分隔线可拖动、双击均分；溢出标签支持滚轮和拖动边缘自动滚动。
- 当前最多四组、同文档单视图；保留上/下/左/右/多行标签栏。跨原生窗口拖动未实现。

## AI 与验证

固定消息锚点、上下条导航、回到最新、字符阅读位置和完成计划收起继续保留。字号覆盖输入、正文、标题与表格。提供商使用小快照；隐藏对话继续接收协议状态，流式合帧不请求绘制。主题切换取消全树插值动画。

回归覆盖：240 次字号预览合为一次保存、慢保存新值、失败重试、并行字段合并；真实文件/终端字号与 UI 缩放期间的控制器和流身份；侧栏保活；方向落点、Escape、最后标签及关闭保护。

原生入口 `integration_test/workbench_redesign_test.dart` 使用 Windows Profile 引擎与内存协议桩，记录 build/raster 帧耗时；不访问真实 profile、SSH、模型或服务器。最终计数与构建记录见 PLAN 和验收包 `BUILD-INFO.json`。测试数据不代替长期、多屏 DPI 或真实账号验收。

## 本机验证结果（2026-11-14）

- 完整 Flutter 回归：316 通过、20 个既有条件跳过、0 失败。最后的桌面几何和隐藏字体修改后，定向回归 62/62 通过；最终分析零问题。配置包原全量 48 通过、1 个旧范围断言失败，更新范围断言并增加兼容性覆盖后相关文件 6/6 通过。
- 原生 Windows Profile：12 个真实文件组件、一次终端 attach、鼠标停靠、双文档与 AI/终端同时可见、缩放与未保存缓冲保留全部通过。物理窗口 1682×1066，DPR 1.25，数据为内存协议桩。
