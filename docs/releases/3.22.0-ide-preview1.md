- 工作区文档模型、独立加密恢复、保存期间编辑保护、冲突审阅和可恢复多文件事务。
- 下载磁盘背压、取消／重连保护、有界搜索、Windows 原生文件监听和后台差异计算。
- LSP、Problems、补全／导航／格式化／重构与 snippet；任务／测试与问题匹配；DAP 调试及断点。
- 编码转换、UTF-8 大文件窗口、跨文件替换预览与整批提交。
- AI 缓冲版本化建议、逐块接受／拒绝／撤销、验证任务和手动行内续写；项目指令、技能、MCP 与共享运行预算。
- 增量会话日志、索引／懒加载、引用保护与有界快照。
- 统一 GUI 入口、生产组件展示、全功能页迁移和自动 contract；消除切换文件触发 AI 整页重建。
- 文档按任务重组：当前指南／规范与历史／证据各有入口，旧开发文档归档，新增模板和检查。

## 使用

完整解压，运行 `启动验收版.cmd`，跟随 [验收指南](../guides/acceptance.md)。默认使用独立 `review-data`。新开发能力需匹配 agent；本地 agent 已随包，远程由用户选择升级。

客户端、Windows 本地 agent 和 Linux amd64 agent 一起编译。agent 清单使用既有发布公钥验证；候选身份以外层名称和 `BUILD-INFO.json` 为准，未对外发布。源码包含未提交改动，准确输入见 `SOURCE-HASHES.json`。
