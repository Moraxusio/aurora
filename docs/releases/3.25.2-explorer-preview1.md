# Aurora 3.25.2-explorer-preview1

> 类型：版本说明 | 状态：候选 | 维护：客户端维护者 | 更新：2026-11-20
> 适用：Windows x64 桌面，沿用 3.25.1 本地及远程 agent

资源管理器改用紧凑的 Windows 11 风格命令栏和上下文菜单。右键文件行只打开一份菜单；空白区域只显示文件夹命令。刷新和排序可从工具栏直接调用，列标题可排序。常用剪切、复制、粘贴、重命名和删除使用图标；低频操作归入「更多选项」。参见 [开始使用](../guides/getting-started.md)。

这次只改客户端。两种签名 agent 与 [3.25.1-agent-preview1](3.25.1-agent-preview1.md) 相同；已经运行 3.25.1 的远端无需再次升级。
