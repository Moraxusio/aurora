# 3.23.0-ai-preview2

> 类型：版本说明 | 状态：候选 | 维护：AI 维护者 | 更新：2026-11-16
> 适用：Windows x64 客户端、本地 agent 与 Linux amd64 agent

## 变化

- AI 页面统一为对话、任务、设置，输入区集中模型、本次发送、附件与发送／停止；设置明确对话覆盖、目录策略与全局默认。
- 每条独立消息可继承／开关／自定义预算，成功发送后消费覆盖，失败保留。补充指令共享预算，排队任务固定接收时配置并独立计量。
- 子代理并发 1–16、单任务总量、禁用与只读策略由服务端执行；子代理不能递归派生，重开子会话保留只读边界。
- 工具单步调用上限、重复确认与 Shell 超时可配置；并发结果逐项落盘，取消主任务等待在途子代理退出。单独停止子代理保留兄弟任务与结果引用。
- 任务搜索／筛选、审批排队／重连恢复、发送快捷键和阅读偏好；模型选择、历史、附件、授权、问题及修改审阅布局整理。
- 保留 OpenCode 兼容协议及 `User-Agent`、`originator`、`x-opencode-client` 身份标识。
