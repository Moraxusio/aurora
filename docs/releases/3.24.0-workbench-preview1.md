# 3.24.0-workbench-preview1

> 类型：版本说明 | 状态：候选 | 维护：项目维护者 | 更新：2026-11-16
> 适用：Windows x64 客户端、Windows 本地 agent、Linux amd64 agent

## 工作台与 GUI

- 重构导航、首页和工具面板层级：常显工具名称、工作区上下文、任务入口、可识别的主要操作与恢复入口。
- 每个服务器独立保留侧栏和当前入口；重连、主题和缩放切换保留搜索条件、提交草稿、筛选及阅读状态。
- Git 提供文字化拉取／推送操作、分仓库草稿和按需构建的更改列表；搜索、服务、端口、代理改用适应窄窗的操作布局。
- 修复本机“开发与问题”入口被过滤；导航支持键盘激活，窄窗底栏常显标签。
- 桌面 150% 缩放时为编辑器和底部终端保留显示空间；文件工具栏在窄侧栏与触控模式下自动换行。
- 文件工具栏换行时保留菜单实例，触控／鼠标切换不会吞掉工作区选择。

## 执行逻辑与可靠性

- 连接请求合并、启动／断开代次和本地 agent 所有权；端口转发串行化、迟到资源回收及持久化失败回滚。
- Git 写操作单飞、确认目标绑定、旧回执隔离；合并／追溯／提交标签绑定原仓库，提交成功保留请求期间的新输入。
- 跨根剪切源删除失败报告部分移动，保留已复制的目标；不清掉后来更换的剪贴板或新变脏的文件标签。
- 非完整搜索拒绝替换预览；终端重连与 UTF-8 状态隔离、握手／心跳资源回收，Windows 终端排空退出输出。
- 终端并发关闭合并为一次分离，正常关闭不再触发重复流回收；待回应心跳及时结束。
- 代理旧连接确认隔离；系统服务同单元操作互斥；日志隐藏暂停轮询、阅读期间缓存更新。
- 任务取消后拒绝迟到完成，调试控制单飞，监控跨重连保活；升级查询旧回执不覆盖新任务。
