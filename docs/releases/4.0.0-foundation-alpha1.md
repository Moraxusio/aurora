# Aurora 4.0.0-foundation-alpha1

> 类型：版本说明 | 状态：候选 | 维护：项目维护者 | 更新：2026-11-21
> 适用：Windows x64 离线单 EXE 原型、Linux amd64 agent 隔离验证

这是 4.0 的工程候选，不是正式版，不用于升级生产环境。已有 3.26.0 ZIP 不变。验收准则见 [ADR 0002](../decisions/0002-single-binary-state-safety.md)。

- Windows 单 EXE 内嵌签名运行包，先验签、解包到用户私有暂存目录、复验完整文件集合，再发布完整运行目录。运行缓存与配置隔离；默认启动新的隔离 Profile，不迁移 3.x。
- agent 身份文件损坏、不完整或已有状态却缺身份时拒绝重置。Windows 新建身份私钥及保存的本地服务配置／代理使用 DPAPI。Linux 可通过独立 systemd 凭据加密新身份私钥；加密身份缺密钥时不退回明文。旧格式兼容读写不表示全量状态已加密。
- 通过 4.x 安装器更新现有受管 Linux 布局时，只替换程序并验证服务；保留配置和单元原件，常规失败恢复程序。3.x 自带的旧升级 worker 不会因此变化。

未达到正式验收门槛：Linux 版本指针与持久恢复状态机、跨版本数据迁移与回退、AI 会话／附件／恢复事务和备份的全量加密，以及客户端程序升级确认仍待实现。不要以 Alpha 文件或单 EXE 发布形式代替上述验收。
