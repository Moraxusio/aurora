# ADR 0001：文档结构与生效规则

> 类型：架构决定 | 状态：生效 | 维护：项目维护者 | 更新：2026-11-16
> 适用：当前仓库文档和后续开发

## 背景

旧根目录同时放着操作指南、几代 GUI 设计、长期总计划、版本流水账和验收结论。相同功能有多份不同时间的说明，旧待办与已实现能力并存，打包脚本仍内嵌旧版本长说明。

## 决定

以 `docs/README.md` 为唯一当前导航入口，按任务分为指南、架构、开发规范、参考、决定、版本和验收；旧文档归入 archive，原始证据保留。每份当前文档声明类型、状态、维护角色、日期及适用范围。

开发、打包共用文档自动检查。包说明来自当前文档，构建记录携带实际版本和源码指纹，不继续在脚本里累计历史版本说明。

## 取舍与落地

移动路径需要同步修复链接、工具与源码中的历史引用；旧 D-* 编号保留，原始日志和哈希不修改成新运行结果。归档材料不再约束新开发。

执行规则见 [文档规范](../standards/documentation.md)，迁移清单见 [历史索引](../archive/README.md)。
