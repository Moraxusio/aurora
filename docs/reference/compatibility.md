# 能力与兼容边界

> 类型：参考 | 状态：生效 | 维护：项目维护者 | 更新：2026-11-16
> 适用：3.24.0-workbench-preview1；上限按当前实现核对

## 平台与外部环境

当前交付为 Windows x64 客户端／本地 agent 和 Linux amd64 远程 agent。Linux agent 使用 systemd 管理安装与远程会话；Windows 本地终端使用 ConPTY，完整退出客户端会结束受管任务，不提供 tmux 持久会话。

本轮实际语言／调试协议验收为 Dart LSP／DAP，需要用户在对应 agent 机器安装 SDK。其它适配器按协议接入，但没有逐个实测。Android 有既有实现，本轮未构建发行包；macOS、iOS、arm64 没有本轮交付验收。

## 资源预算

| 对象 | 当前边界 |
|---|---|
| 完整文本源文件 | 4 MiB；较大 UTF-8 使用 64 KiB 只读字节窗口 |
| LSP 同步 | 超过 512 Ki 字符或 JSON 帧预算时暂停 |
| 搜索结果 | 全局 2000 条；截断后应缩小范围 |
| 下载／文本传输 | 共享 3 个并发槽；下载逐帧写盘 |
| 替换预览 | 最多 128 文件、8 Mi 字符；单输入／输出 4 MiB |
| 底层恢复事务 | 512 目标、单文件 64 MiB、前后版本合计 256 MiB |
| 会话存储 | 单正文 64 MiB；空闲缓存最多 8 会话／约 64 MiB 磁盘体积 |
| 开发配置 | 256 KiB，16 LSP、128 任务、32 调试配置 |
| 开发进程 | LSP／DAP／任务／MCP 共享 8 个配额 |
| 工作区任务 | 4 组并发；每组 128 Ki 字符日志、500 问题／测试项；12 组历史 |
| 终端会话名称 | Windows／Linux 共用 1–64 字符校验 |
| AI 默认运行预算 | 60 步、900 秒、500000 tokens、2 MiB 输出；每项 0 表示不限 |
| AI 子代理 | 并发 1–16（默认 1），单任务总量 0–1000（默认 32，0 不限）；禁止递归派生 |
| AI 工具策略 | 每步 1–64 调用；重复确认阈值 0–20（默认 3）；Shell 默认／最大超时 1–600 秒 |
| AI 附件 | 8 MiB／件；文本 256 KiB；8 件／条、合计 20 MiB；库 512 MiB |
| AI 快照默认 | 已跟踪单文件 8 MiB、新文件最多 2 MiB、单树 128 MiB／200000 有效文件、存储 512 MiB、超时 60 秒；可配置 |

“磁盘体积”不是进程 RSS 上限。大规模子会话删除可能先达到事务目标数：超限整批拒绝，先删除部分子会话再重试。

运行预算可配置正值最大为 10000 步、604800 秒、10 亿 tokens、1 GiB 输出、100 万 USD；0 取消对应运行限制，单请求、工具与存储的独立约束仍存在。快照设置中 0 表示使用默认，正值最大为 200 万有效文件、单文件 64 MiB、单树 1 GiB、对象库 16 GiB、超时 600 秒。快照差异记录仍最多 128 文件／步骤，超出明确报告，不能声称完整恢复点。

逐消息运行覆盖由 `ai.run.options` 上报；项目控制表单依赖 `controls_version: 1`。预算关闭仍计量。补充指令共享当前任务预算，排队项开始时重建独立计量与截止时间，并使用接收时固定的配置。重启后待发送输入与显式覆盖保留，接收时内存策略快照不保留，需显式重新发送并重新读取项目策略。

并发仅限同一步相邻 subagent 调用，以并发上限分批执行；普通工具是顺序屏障。子代理共享工作目录、主任务预算和并发槽。只读身份和禁止递归在服务端强制执行，重新打开子会话也不能解除。

## 功能限制

- LSP 资源重构限普通文本文件；Windows 仅大小写重命名明确拒绝。
- snippet 支持字段、默认值、变量、选择和镜像，正则转换未实现。
- AI 待审建议与验证版本关联在内存；接受后的未保存正文由文档恢复保护。行内续写通过 `Alt+\` 手动触发。
- MCP 支持 stdio／Streamable HTTP 的工具、资源、提示词；resource templates、OAuth 与跨运行持久连接未实现。
- 本地项目选择暂不支持 UNC／网络共享。
- Git 提交草稿与工具筛选按服务器／仓库保留在本次客户端会话中；它们不属于跨应用重启的文档恢复记录。
- 代理支持 Trojan、Hysteria2、VLESS、VMess 的已实现传输；Reality、XTLS Vision、gRPC 等扩展不因节点可导入就表示可连接。
- Windows 授权出口不解析 PAC-only／自动发现代理。模型资格与图片／PDF 能力由实际账号、模型和网关决定。
