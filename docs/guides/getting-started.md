# 开始使用

> 类型：使用指南 | 状态：生效 | 维护：客户端维护者 | 更新：2026-11-16
> 适用：3.24.0-workbench-preview1 Windows x64 完整候选

## 启动和项目

完整解压 ZIP。候选包双击 `启动验收版.cmd`，配置保存在包内 `review-data`，首次为空白工作区；普通包运行 `aurora.exe`。

选择“打开本机文件夹”添加一个项目。文件、终端、任务和 AI 工具运行在 Windows 本机；PowerShell、Git、Dart 等开发工具需要安装在本机。候选的配置隔离不会复制项目文件，验收可先使用临时示例项目。

远程开发选择“添加服务器”，经 SSH 验证主机身份、安装签名 Linux agent，再使用 TLS 直连。新功能需要同版本 agent；应用会提示更新，由用户发起。远程 LSP、DAP 与任务使用服务器上的工具链。

## 工作台

中央为文档网格，右侧为 AI，底部为终端。拖动标签或分隔线调整布局，切换、隐藏和缩放保留正文、撤销、草稿、阅读位置及连接。

左侧导航同时显示图标与名称：文件、搜索、Git、终端、AI，以及开发、监控、服务、端口和代理。本机也提供“开发”入口；Linux 专属服务按环境显示。没有打开文档时，首页提供终端、快速打开、项目搜索、命令面板和概览入口。

顶部显示当前服务器和项目；点击切换服务器，`Esc` 关闭切换列表。每台服务器保留自己的侧栏选择、搜索条件和 Git 提交草稿。断线时显示连接恢复入口，重连刷新数据；已访问的侧栏继续使用原有视图。窄窗一次显示侧栏或正文，底部导航文字保持可见。

| 操作 | 快捷键 |
|---|---|
| 设置 | `Ctrl+,` |
| 命令面板 | `Ctrl+Shift+P` |
| 快速打开 | `Ctrl+P` |
| 项目搜索 | `Ctrl+Shift+F` |
| 文件侧栏 | `Ctrl+B` |
| 终端面板 | `Ctrl+J` |
| 聚焦终端／新建终端 | `Ctrl+反引号`／`Ctrl+Shift+反引号` |
| AI 面板 | `Ctrl+Alt+I` |
| 文档组分屏 | `Ctrl+\` |
| 关闭当前文档 | `Ctrl+W` |

设置 → 外观可调整界面、文件和终端字号、主题及整体缩放；“统一组件展示”可检查实际生产控件。

## 文件与恢复

编辑缓冲属于工作区，未保存内容写入独立加密恢复记录。关闭或退出时按照界面提示处理未保存内容；外部文件已变更时通过冲突审阅决定合并，不自动覆盖。恢复坏记录会保留原始数据并显示错误。

编码、大文件阅读、语言服务、格式化、跨文件替换、任务和调试见 [开发工具](development-tools.md)。Git、搜索和差异使用当前工作区；批量修改以预览结果和提交时版本校验为准。

跨文件根剪切会先完成目标复制，再删除源文件。若源删除失败，界面报告“部分移动”，目标副本和源文件同时保留；按提示核对后处理重复文件。不会因源删除失败再回滚已经成功的目标副本。

## 常用工具

- **搜索**：顶部可见当前范围；输入关键词后搜索，使用 `Aa`、`ab`、`.*` 调整匹配。筛选、替换和结果共享滚动区域，窄窗仍能到达全部操作。取消、读取失败、超时或超限得到的非完整结果不能进入替换预览；调整范围后重新搜索。
- **Git**：先确认仓库和分支，再暂存并填写说明。拉取、推送在仓库下方直接可见；每个仓库保留独立的会话内草稿。提交完成不会清掉等待期间新输入的说明。确认框打开后若仓库或连接变化，需在目标仓库重新操作；差异、追溯、提交和合并标签始终绑定打开时的仓库。
- **系统服务**：按名称／说明筛选，默认查看运行中和失败的服务，可切换“全部服务”。点击服务看日志；操作期间禁用同一服务的重复请求。日志跟随时向上阅读会缓存新内容，回到最新位置后再显示；隐藏日志页暂停轮询。
- **端口**：使用“新建转发”填写目标地址和可选本机端口，也可从监听列表选择。输入错误留在表单中修正；保存失败会关闭本次新开的监听，删除保存失败则保留现有监听。
- **代理**：添加来源后，用统一搜索框筛选所有来源的节点；测速从当前服务器发起。当前节点、待同步或失败状态在面板顶部显示，并提供刷新。删除来源只移除客户端记录，服务器节点在显式清除前保留。

## 终端、监控与退出

Windows 终端优先使用已安装的 `pwsh`，否则使用 Windows PowerShell。终端出口可选择系统代理、agent 节点或直连；已存在的会话保持建立时的出口。

监控展示系统、磁盘、进程和可用的 GPU 数据；NVIDIA GPU 详情需要驱动及 `nvidia-smi`，未知数据显示“—”。展开详情和后台刷新独立运行。

点窗口关闭按钮会隐藏到托盘。需要停止本地 agent 和受管任务时，从托盘菜单选择退出；远程 tmux 会话的生命周期由远程 agent 管理。

## 遇到问题

先检查工作区是本机还是服务器、连接及服务是否开启、agent 是否匹配、对应机器是否装好工具。命令面板“复制界面诊断”可提供有界 GUI 异常摘要。反馈时附版本、操作步骤、预期／实际结果与脱敏截图；能力边界见 [参考](../reference/compatibility.md)。
