# 独立区域工作台（3.17.0 + Windows 重构验收）

**位置可以变，工作不能丢。** 当前源码将文件、差异、PDF 与设置放在文档网格，AI 对话放在独立右侧栏，PowerShell/远程终端及会话列表放在底部。任务区域不再互相冒充文档标签或替换文件树。完整设计及参考代码见 [IDE_REDESIGN.md](IDE_REDESIGN.md)。

## 排布与拖放

- 标题栏“布局”：图形化选择**单页、左右分屏、上下分屏、三列、四宫格**。每个视图只有一条标签栏，不再常驻“编辑组 N”标题和重复布局按钮。
- 预设只改变排布：已有视图、标签归属、活动项与焦点保持；新增格子为空，减少格子才合并标签。切换左右/上下不会重新分配任务。
- 一个视图可以有多个文档标签，最多同时 4 个视图。新建分屏保留当前文档并增加空视图，便于继续打开另一个文件；不复制同一文档。AI 和终端都不参与文档分屏或跨宿主拖放。
- 工具栏分屏按钮与快捷键新建空视图，不搬走当前文档；拖放或标签菜单才移动文档。唯一标签拖到自己的正文边缘不会产生空组，跨组最后标签改为移动原组。Escape 取消当前拖放。Windows 重构验收版提供正文五向停靠标记，中央移入、四向分屏；边缘热区为视口 18%，限制为水平 36–110px、垂直 36–90px。
- 拖到标签前半部/后半部：插到前面/后面；拖到列表末尾空位：放在最后；拖到另一视图正文中央：移入；拖到正文边缘：在对应方向分屏。只显示当前落点的一块预览或插入线，悬停不改布局，放下才提交，取消保持原位。触屏长按标签再拖动。
- 长标签栏拖到边缘自动滚动，普通鼠标滚轮也能横移。不便拖动时，右键标签可固定、分屏、移到指定视图；标签栏 `…` 可以分屏、放大/还原或**合并此视图**。合并只是移动文档标签，不关闭任何文档，也不影响右侧 AI 或底部终端。
- 关闭最后一个标签时，空白视图自动收拢；主动选择的空白视图仍可接收新任务。放大当前视图不会改变原布局树，还原后保持原排布和比例。
- Windows 重构验收版单击标签即时激活，双击放大/还原分组，中键关闭；主侧栏隐藏/显示及抽屉切换保留文件树。

## 标签位置与宽度

“布局”及标签栏 `… → 标签栏与布局…` 提供：**顶部、底部、多行、左侧、右侧**。每个视图独立拥有自己的标签列表，位置偏好按当前项目统一应用。

- 主侧栏与编辑区之间、纵向标签列表与正文之间，都可以直接拖动分隔条；悬停/拖动时高亮。**双击分隔条**恢复默认值。
- 视图之间的分隔条可拖动改变横向/纵向比例，双击恢复均分。
- 后续减法验收版的所有分隔线按按下后的指针总位移定位，同帧高频事件不会互相覆盖，整体 UI 缩放也按正确比例移动；中等宽度文件侧栏并排展开，不覆盖正文。
- “布局”里展开“标签宽度”，用滑块调整横向标签宽度（100–260 px）。纵向列表记忆宽度 120–400 px，主侧栏记忆宽度 180–640 px；实际显示按可用空间约束，避免把正文挤到不可用。
- 顶部多行显示最多三行，更多内容可滚动；单行和纵向列表使用惰性列表。三种列表切换活动标签、重排或调整尺寸后都会让活动项保持可见。横向溢出或纵向标签栏中的下拉可直接选择该视图的所有标签。
- 每个正文和欢迎页按自己的可用矩形裁剪；左/右标签栏与相邻视图不会被正文覆盖。

## 底部终端

- 活动栏“终端”打开底部面板，文件树保持原位。面板内可新建、切换、刷新和结束会话，支持拖高、最大化/还原及隐藏。
- 隐藏只是收起：输出、连接及本地任务继续保留。关闭本地终端视图会结束对应任务；关闭远程视图只断开显示，远程 tmux 继续运行。会话列表中的“结束”明确结束程序并要求确认。
- 真正窄窗或高度不足 360 时临时只显示当前焦点区域，放大后恢复原文档树与面板高度。Windows 重构验收版中，AI 旁边的桌面列不再因局部宽度低于 600 而隐藏终端；面板较窄时会话列表与正文切换显示。
- 终端异步连接不能从文件、菜单或弹窗抢焦点；刷新旧连接的结果不会关闭新连接的视图，结束失败也不关闭视图。

## 安全地切换、固定和关闭

- 同一标签只有一个活动视口和一份状态；切换排布、拖动到另一视图、调整宽度和窄屏切换不重开文档，不重建终端连接。
- 固定标签优先排在当前视图前面；“关闭其它 / 后续 / 未固定标签”跳过固定项。明确点关闭按钮或 Ctrl+W 仍可关闭固定项，未保存确认不变。
- 批量关闭采用操作开始时的标签实例快照；取消未保存提示就停止，期间切换项目（包括切走再切回）会停止后续关闭，关闭后重开的同名标签也不会被旧操作误关。重复关闭同一标签只询问一次。
- 焦点属于当前视图，状态栏、Ctrl+W 和标签切换都跟随它；点击标签或切换视图时恢复该任务内的输入焦点。

| 快捷键 | 操作 |

## 小窗口、手机和布局记忆

小幅缩放先压缩网格约束，不在所有分组最小尺寸之和附近反复切成单组。真正窄屏或主动放大时只显示当前视图，标签栏提供视图切换；还原保留原树与比例。AI 宽度单独拖动，窄屏按当前焦点区域切换，隐藏不关闭。纵向标签在视图过窄时临时回到顶部，偏好不被覆盖。

每个项目（含“浏览服务器”）分别记住文件路径、组、顺序、固定、活动文件、分隔比例、标签位置和宽度。浏览视图额外记忆终端 `panel_height` 与 AI `assistant_width`，不记会话 ID、可见性、最大化或输入。沿用原 DPAPI/Keystore 加密配置，视图字段可选，旧配置无需重置。只保存文件引用与布局：**不保存未保存文字，不自动复活本地终端进程，也不声称恢复正在运行的 AI 任务**。服务标签在本次运行内继续保留。

首版不提供跨服务器/跨项目拖放、同一文档的重复视图、浮动系统窗口和无限组。组件测试和截图验证不替代真实桌面拖放、多屏 DPI、触摸设备及可访问性实机验收。
