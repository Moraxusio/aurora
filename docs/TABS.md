# 标签页优先工作台（3.14.0）

**位置可以变，工作不能丢。** 文件、PowerShell/远程终端、AI 会话、差异、PDF 与设置都是标签。侧栏负责发现和打开，编辑组负责组织工作，不要求切换功能就离开当前任务。

## 排布与拖放

- 标题栏或任一编辑组右上角的“标签与编辑区布局”菜单：**单组、左右、上下、三列、四宫格**。
- 一个编辑组可以有多个标签，最多同时 4 组。单个标签也可向右/向下拆分，原组留下空位，便于继续打开另一个任务；不会复制同一个终端或文件。
- 拖到另一个标签前面：重排；拖到列表末尾空位：放在最后；拖到编辑区中央：移入该组；拖到编辑区四边：在对应方向新建组。拖动时显示落点预览，取消拖动不改变布局。触屏长按标签再拖动。
- 不便拖动时，右键标签可固定、拆分、移到指定组；编辑组“…”里可以拆分或**合并此组**。合并只是移动标签，不关闭文件、终端或 AI。
- 关闭最后一个标签时，空组自动收拢；主动选择的空组仍可接收新任务。

## 标签位置与宽度

同一个布局菜单提供：**顶部单行、底部单行、顶部多行、左侧纵向、右侧纵向**。每组独立拥有自己的标签列表，位置偏好按当前项目统一应用。

- 主侧栏与编辑区之间、纵向标签列表与正文之间，都可以直接拖动分隔条；悬停/拖动时高亮。**双击分隔条**恢复默认值。
- 编辑组之间的分隔条可拖动改变横向/纵向比例，双击恢复均分。
- “调整单个标签宽度…”使用滑块调整横向标签宽度（100–260 px）。纵向列表记忆宽度 120–400 px，主侧栏记忆宽度 180–640 px；实际显示按可用空间约束，避免把正文挤到不可用。
- 首版顶部多行显示最多三行，更多内容可滚动；单行和纵向列表使用惰性列表。三种列表切换活动标签、重排或调整尺寸后都会让活动项保持可见。右上角下拉可直接选择该组的所有标签。

## 安全地切换、固定和关闭

- 同一标签只有一个活动视口和一份状态；切换排布、拖动到另一组、调整宽度和窄屏切换不重开文档，不重建终端连接。
- 固定标签优先排在该组前面；“关闭其它 / 后续 / 此组未固定标签”跳过固定项。明确点关闭按钮或 Ctrl+W 仍可关闭固定项，未保存确认不变。
- 批量关闭采用操作开始时的标签实例快照；取消未保存提示就停止，期间切换项目（包括切走再切回）会停止后续关闭，关闭后重开的同名标签也不会被旧操作误关。重复关闭同一标签只询问一次。
- 焦点属于编辑组，状态栏、Ctrl+W 和组内切换都跟随当前组；点击标签或切换组时恢复该任务内的输入焦点。

| 快捷键 | 操作 |
|---|---|
| Ctrl+\ | 向右拆分当前编辑组 |
| Ctrl+Shift+\ | 向下拆分当前编辑组 |
| Ctrl+1 / 2 / 3 / 4 | 聚焦对应编辑组 |
| Ctrl+Tab / Ctrl+Shift+Tab | 当前组的下一个 / 上一个标签 |
| Ctrl+Shift+PageUp / PageDown | 当前标签前移 / 后移（不越过固定区域） |
| Ctrl+W | 关闭当前组的活动标签 |
| Ctrl+B | 显示 / 隐藏主侧栏 |

## 小窗口、手机和布局记忆

编辑区不够容纳当前分组时，只显示当前组，组标题显示“聚焦”；点组标题可选择其他组。放大窗口恢复原排布和比例，不把隐藏组当成关闭。纵向标签在编辑组过窄时临时回到顶部，偏好不被覆盖。

每个项目（含“浏览服务器”）分别记住文件路径、组、顺序、固定、活动文件、分隔比例、标签位置和宽度。沿用原 DPAPI/Keystore 加密配置，视图字段可选，旧配置无需重置。只保存文件引用与布局：**不保存未保存文字，不自动复活本地终端进程，也不声称恢复正在运行的 AI 任务**。服务标签在本次运行内继续保留。

首版不提供跨服务器/跨项目拖放、同一文档的重复视图、浮动系统窗口和无限组。组件测试和截图验证不替代真实桌面拖放、多屏 DPI、触摸设备及可访问性实机验收。
