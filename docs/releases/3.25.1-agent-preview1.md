# Aurora 3.25.1-agent-preview1

> 类型：版本说明 | 状态：候选 | 维护：构建维护者 | 更新：2026-11-20
> 适用：Windows x64 客户端与本地 agent、Linux amd64 远程 agent

保留 [3.25.0-gui-preview14](3.25.0-gui-preview14.md) 的功能。本次将客户端和两种 agent 统一提升到 `3.25.1` 并重新签名 agent。早期和后期预览使用过内容不同、版本号却相同的 `3.25.0` agent；远程升级不覆盖同版本，早期 agent 因此可能仍把完全权限回落为先询问。

远程工作区从「服务器概览 → agent 版本 → 检查并升级」确认升级，重连后检查实际连接版本显示 `3.25.1`。随后在「此对话的执行策略」中选择「完全权限」并确认发送后不回落。发布客户端包不会自动更改远程服务器。

直接运行 `aurora.exe` 使用常规配置；`启动验收版.cmd` 使用独立验收配置。两种方式都随包使用 `3.25.1` 本地 agent。
