# Aurora 3.26.0-safety-preview1

> 类型：版本说明 | 状态：候选 | 维护：客户端维护者 | 更新：2026-11-21
> 适用：Windows x64 客户端及本地 agent、Linux amd64 远程 agent

- 包含 3.25.3 打包后补齐的子代理即时撤权、文件和上传目标校验。
- Windows 下载在发布到最终文件名时不覆盖其它程序刚创建的同名文件。
- 文件粘贴替换由 agent 事务提交，并把收据与目标写入一起落盘。丢失响应后可从文件栏查询；不会自动重试替换或删除剪切源。支持两个普通文件，每个最多 64 MiB；目录、符号链接、大文件和旧 agent 请选择保留两者。
- AI 回退默认只回退对话。要恢复文件，必须明确勾选预览列出的目标；新 agent 校验预览版本与所选文件，拒绝旧客户端发来的无审阅文件回退。快照仍不能判定改动来自 AI 还是手动保存。
- 本地候选，不会自动升级远程 agent；未改变远程默认运行用户，也不包含安装器。
