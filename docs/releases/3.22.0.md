# 3.22.0：完整 IDE 能力与统一工作台

> 类型：版本说明 | 状态：生效 | 维护：项目维护者 | 更新：2026-11-16
> 适用：Windows x64 正式客户端、Windows 本地 agent、Linux amd64 agent

## 下载与升级

[GitHub Release](https://github.com/Moraxusio/aurora/releases/tag/v3.22.0) 提供完整 Windows ZIP、ZIP SHA-256 sidecar 和 `SHA256SUMS.txt`。

完整解压 `Aurora-3.22.0.zip` 后运行 **`aurora.exe`**。正式版使用当前 Windows 用户的正常 Aurora 配置；先前验收包的 `review-data` 是独立配置。远程开发的新能力需要匹配的 3.22.0 agent，由客户端提示、用户选择升级；本地 agent 已随包提供。

## 主要成果

### 文档与文件可靠性

- 工作区统一管理正文、选区、撤销、版本和保存点；视图切换、隐藏和缩放保留编辑状态。
- 未保存正文使用独立加密恢复，保护保存期间继续输入；外部修改进入冲突审阅。
- 文件保存、AI 修改、批量替换及会话回退共用可恢复事务，提交时逐项核对版本；中断后恢复或明确阻止继续写入。
- 下载逐帧写盘并控制并发，补齐取消／重连保护、Windows 原生监听和有界搜索。

### IDE 与开发工具

- LSP 提供诊断、Problems、补全、hover、导航、格式化、重命名、代码操作及 snippet。
- 任务／测试支持依赖、取消／重跑、输出、问题匹配和历史；DAP 接入断点、线程／调用栈、变量、监视与单步。
- 支持 UTF-8／UTF-16 和旧编码转换、UTF-8 大文件只读窗口、跨文件替换预览及整批提交。

### AI 协作与存储

- 基于未保存缓冲、选区和诊断生成版本化修改建议，逐块接受／拒绝／撤销，整批保存并关联验证任务；支持手动行内续写。
- 分层项目指令、按需技能、MCP stdio／Streamable HTTP 工具／资源／提示词，以及共享时间、步数、token、输出和费用预算。
- 会话采用增量 journal、索引和正文懒加载，提供检查点、引用保护和有界快照。
- 保留 OpenCode 兼容协议及 `User-Agent`、`originator`、`x-opencode-client` 标识。

### 统一 GUI 与开发文档

- 功能页统一使用 Aurora 组件、语义 tokens、面板和浮层；设置提供生产组件展示，自动 contract 约束后续接入。
- 消除切换文件引起的 AI 整页重建，保持对话草稿、阅读位置及终端连接。
- 20 份旧文档归档，建立指南／架构／开发／参考／决定／版本／验收目录、模板与自动检查；入口为 [文档导航](../README.md)。
