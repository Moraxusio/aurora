# 开始使用

> 类型：使用指南 | 状态：生效 | 维护：客户端维护者 | 更新：2026-11-20
> 适用：3.25.0 Windows 桌面客户端

## 启动和项目

完整解压 ZIP。候选包双击 `启动验收版.cmd`，配置保存在包内 `review-data`，首次为空白工作区；普通包运行 `aurora.exe`。

选择“打开本机文件夹”添加一个项目。文件、终端、任务和 AI 工具运行在 Windows 本机；PowerShell、Git、Dart 等开发工具需要安装在本机。候选的配置隔离不会复制项目文件，验收可先使用临时示例项目。

远程开发选择“添加服务器”，经 SSH 验证主机身份、安装签名 Linux agent，再使用 TLS 直连。新功能需要同版本 agent；应用会提示更新，由用户发起。远程 LSP、DAP 与任务使用服务器上的工具链。

## 工作台

中央为文档网格，右侧为 AI，底部为终端。没有文档时，AI 或终端会接管空出的编辑区；只开 AI 时它会紧邻左侧栏。打开文档即恢复布局及原来的面板宽度。拖动标签或分隔线可调整布局；切换、隐藏和缩放保留正文、撤销、草稿、阅读位置及连接。

左侧导航提供文件、Git 等视图，终端和 AI 会打开各自面板。Linux 专属服务按环境显示。桌面上点击标题栏的搜索入口，在同一个输入框切换文件名、文件内容和命令；只有文件内容搜索会打开侧栏结果。未打开文档和面板时，首页保留快速打开或连接等起步操作。

顶部显示当前服务器和项目；点击切换服务器，`Esc` 关闭切换列表。每台服务器保留自己的侧栏选择、搜索条件和 Git 提交草稿。断线时显示连接恢复入口，重连刷新数据；已访问的侧栏继续使用原有视图。窄窗一次显示侧栏或正文，底部导航文字保持可见。

| 操作 | 快捷键 |
|---|---|
| 设置 | `Ctrl+,` |
| 命令面板 | `Ctrl+Shift+P` |
| 快速打开 | `Ctrl+P` |
| 项目搜索 | `Ctrl+Shift+F` |
| 文件侧栏 | `Ctrl+B` |
| 终端面板 | `Ctrl+J` |
| 聚焦终端／新建终端 | `Ctrl+反引号`／`Ctrl+Shift+反引号` |
| AI 面板 | `Ctrl+Alt+I` |
| 文档组分屏 | `Ctrl+\` |
| 关闭当前文档 | `Ctrl+W` |

设置 → 外观可调整界面、文件和终端字号、主题及整体缩放；“统一组件展示”可检查实际生产控件。

## 文件与恢复

文件侧栏的命令栏提供「新建」、刷新（`F5`）、排序、筛选和定位当前文件。宽侧栏的表头可以点按排序，窄侧栏优先显示文件名。右键或长按文件行，常用的剪切、复制、粘贴、重命名和删除在菜单顶部用图标表示；不适用于所选项的操作不会显示或会禁用。「更多选项」包含相对路径、创建副本和工作区管理；文件夹大小在「属性」中按需统计。右键空白处只显示对当前目标文件夹适用的命令，不会弹出根文件夹的菜单。键盘可用 `Shift+F10` 打开菜单，`Alt+Enter` 查看属性。

在桌面文件树单击文件会复用当前编辑组的预览标签（斜体）；双击文件或预览标签、按 `Enter` 打开文件、或直接编辑，都会保留标签。预览不进入重启恢复的标签列表；未保存的编辑仍正常恢复。编辑器路径和常用操作合为一行，自动换行、编码、语言服务及 AI 编辑操作可在 `…` 菜单找到。

编辑缓冲属于工作区，未保存内容写入独立加密恢复记录。关闭或退出时按照界面提示处理未保存内容；外部文件已变更时通过冲突审阅决定合并，不自动覆盖。恢复坏记录会保留原始数据并显示错误。

编码、大文件阅读、语言服务、格式化、跨文件替换、任务和调试见 [开发工具](development-tools.md)。Git、搜索和差异使用当前工作区；批量修改以预览结果和提交时版本校验为准。

跨文件根剪切会先完成目标复制，再删除源文件。若源删除报错，不会回滚已经成功的目标副本；断线时源删除可能已经完成，重试前请核对两处。3.26.0 支持普通文件的事务替换（两端文件各不超过 64 MiB）。断线后从文件栏「查询替换结果」向原 agent 查询；不会自动重放替换或删除源文件。查询入口随当前客户端工作区保留，退出客户端前建议记下操作编号。目录、符号链接、大文件或旧 agent 请选择「保留两者」。若恢复 3.25.x 中断的替换，还要检查隐藏的 `.aurora-old-…` 旧暂存项。

4.0 后续开发源码已支持重启后继续查询：客户端提交前在加密 Profile 中保存收据编号、目标和 agent 身份。客户端关闭前无需手记编号；重连原 agent 后仍由用户在文件栏发起查询，查询既不会复制文件，也不会删除源文件。加密 Profile 保存失败时不发送替换。已打包的 `4.0.0-foundation-alpha1` 不包含这项改动。

文件确认期间若连接或工作区改变，需要在目标处重新执行。上传新文件不会覆盖临时出现的同名项；确认替换只允许替换当时看到的版本。上传失败且连接已经更换时，请从文件侧栏重新发起，不会沿用旧连接上的覆盖确认。

Windows 下载若在写入最终文件名时发现同名目标，保留原文件并报冲突；请选择其它名称重新下载。

## 常用工具

- **搜索**：`Ctrl+P`、`Ctrl+Shift+F`、`Ctrl+Shift+P` 打开同一搜索浮层的文件名、文件内容、命令模式。用上下箭头选择，`Enter` 打开文件、执行命令或显示内容结果，`Esc` 返回原处。侧栏的 `Aa`、`ab`、`.*` 及选项菜单管理匹配、路径筛选和跨文件替换。窄窗仍可从底部搜索进入结果与输入。非完整搜索（取消、读取失败、超时或超限）不能进入替换预览。
- **Git**：先确认仓库和分支，再暂存并填写说明。拉取、推送在仓库下方直接可见；每个仓库保留独立的会话内草稿。提交完成不会清掉等待期间新输入的说明。确认框打开后若仓库或连接变化，需在目标仓库重新操作；差异、追溯、提交和合并标签始终绑定打开时的仓库。
- **系统服务**：按名称／说明筛选，默认查看运行中和失败的服务，可切换“全部服务”。点击服务看日志；操作期间禁用同一服务的重复请求。日志跟随时向上阅读会缓存新内容，回到最新位置后再显示；隐藏日志页暂停轮询。
- **端口**：使用“新建转发”填写目标地址和可选本机端口，也可从监听列表选择。输入错误留在表单中修正；保存失败会关闭本次新开的监听，删除保存失败则保留现有监听。
- **代理**：添加来源后，用统一搜索框筛选所有来源的节点；测速从当前服务器发起。当前节点、待同步或失败状态在面板顶部显示，并提供刷新。删除来源只移除客户端记录，服务器节点在显式清除前保留。

## 终端、监控与退出

点击左侧「终端」或按 `Ctrl+J` 显示或隐藏面板。终端默认把整块面板留给输出：点当前会话名可切换或管理全部会话，`+` 新建，`…` 可最大化、还原或关闭当前视图。关闭远程视图不结束会话；结束本地终端或从列表结束会话会要求确认。翻阅历史时，右下角箭头只在需要时出现，可回到最新输出。

Windows 终端优先使用已安装的 `pwsh`，否则使用 Windows PowerShell。终端出口可选择系统代理、agent 节点或直连；已存在的会话保持建立时的出口。

监控展示系统、磁盘、进程和可用的 GPU 数据；NVIDIA GPU 详情需要驱动及 `nvidia-smi`，未知数据显示“—”。展开详情和后台刷新独立运行。

点窗口关闭按钮会隐藏到托盘。需要停止本地 agent 和受管任务时，从托盘菜单选择退出；远程 tmux 会话的生命周期由远程 agent 管理。

## 遇到问题

先检查工作区是本机还是服务器、连接及服务是否开启、agent 是否匹配、对应机器是否装好工具。命令面板“复制界面诊断”可提供有界 GUI 异常摘要。反馈时附版本、操作步骤、预期／实际结果与脱敏截图；能力边界见 [参考](../reference/compatibility.md)。
