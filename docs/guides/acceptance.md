# 验收指南

> 类型：使用指南 | 状态：候选 | 维护：项目维护者 | 更新：2026-11-16
> 适用：Aurora 3.24.0-workbench-preview1，Windows x64

## 启动

1. 将完整 ZIP 解压到可写目录，双击 **`启动验收版.cmd`**。
2. 首次使用独立空配置，选择“打开本机文件夹”。建议在临时目录放几个文本／Dart 文件开始。
3. `review-data` 保存本次验收的配置、恢复和本地 agent 状态。启动器使用独立实例名；直接运行 `aurora.exe` 会使用普通启动配置。
4. 本包同时含新编译的 Windows 本地 agent 与 Linux amd64 agent。远程环境需要用户自行选择升级；本地验收无需部署服务器。

## 建议顺序与预期

| 操作 | 预期 |
|---|---|
| 编辑两个文件并撤销／重做，反复切换标签 | 正文、撤销与选区保留；AI 面板不因切文件重置 |
| 拖侧栏、分屏、隐藏 AI／终端，切明暗和缩放 | 面板跟随，草稿、连接和阅读锚点保留 |
| 未保存文件后完整退出并重开 | 根据退出选择保存／保留恢复；重新进入工作区可恢复缓冲 |
| 在其它编辑器修改同一文件后保存 | 检测冲突并可审阅，不静默覆盖 |
| 搜索并预览跨文件替换，再接受／撤销 | 预览对应当前缓冲；整批保存校验全部版本 |
| 选择 UTF-8／UTF-16／旧编码，查看大 UTF-8 文件 | 明确编码；超限进入只读窗口；不能表示的字符拒绝保存 |
| 打开设置 → 外观 → 统一组件展示 | 按钮、字段、面板、列表统一；键盘、窄窗和缩放可操作 |
| 在终端执行命令、切换／隐藏面板 | 保持同一会话，不因布局创建重复连接 |
| 展开监控详情并连续滚动 | 有数据正常显示；缺少设备能力显示明确空状态 |
| 在搜索／Git／服务侧栏填写条件或草稿，切换服务器再返回 | 各服务器保留自己的内容和当前入口 |
| 断开再重连，切换主题与 150% 缩放 | 侧栏身份保留，数据刷新；Git 说明和搜索条件不丢失 |
| Git 切仓库、提交过程中继续写下一次说明 | 草稿按仓库隔离；完成回执不清除新输入 |
| 日志开启跟随后向上阅读，等待新日志 | 阅读位置不跳动，新内容提示待查看；隐藏页暂停轮询 |
| 窄窗中使用搜索、服务筛选、新建转发和代理筛选 | 字段与操作可滚动、可换行；错误保留输入并可重试 |

## IDE 验收

在本地 agent 机器安装 Dart SDK，并确保从应用启动环境可找到 `dart`。参照 [开发配置](development-tools.md) 将配置写入示例项目 `.aurora/development.json`：

- 建一个有明确语法错误的 `.dart` 文件，检查 Problems、定位、补全／hover／定义。
- 格式化或重命名，检查预览、接受和单步撤销；预览后改正文，检查旧结果失效。
- 跑任务／测试，检查退出码、定位、取消／重跑和重启后的历史。
- 在示例程序可执行行打断点，启动调试，检查线程／栈、变量、监视和单步；编辑行后检查断点位移。

## AI 验收

配置自己的模型连接后，检查当前未保存缓冲／选区附件、AI 修改建议、逐块接受／拒绝／撤销／保存、验证任务及手动行内续写。工具调用的写文件权限按当前策略确认。

按 [扩展配置](development-tools.md) 测试项目指令、技能、一个自备 MCP 服务、运行预算和会话重开。真实账号、模型资格、模型质量与 MCP 服务行为需要在你的环境中验证。

已有 AI 功能按 [AI 配置指南](ai.md) 回归：

1. 在 **对话 / 任务 / 设置** 间切换，确认草稿与阅读位置保留；打开设置的连接、模型、权限和对话显示页面，宽窄窗均可导航。
2. 输入框打开 **本次发送**，关闭预算或自定义限额、调整并发后应用；发送失败应保留，成功后恢复继承。运行时改为排队发送验证独立预算，补充指令沿用当前任务。
3. 从对话菜单打开 **此目录的项目策略**，设置代理并发、总量、只读与工具超时；保存后用于新发送，已有排队项保持原策略。
4. 在 **快照与回退** 保存忽略规则，点击「检查快照范围」；小预算停止后查看实际用量与原因，调整后使用“继续任务（新预算）”。
5. **任务**页查看并发子代理、审批和输出；单独停止一个子代理应保留其它任务，停止主任务应取消全部在途子代理。子代理不可继续派生，重开只读子会话仍为只读。
6. 检查多审批逐项处理、失败重试、重连恢复、附件重试、待发送输入移除／重发，以及设置关闭不应用草稿。
7. 切换明暗、窄窗和文字缩放；调整 Enter / Ctrl+Enter，确认中文组合输入不误发送。

## 反馈与退出

反馈至少写：`3.24.0-workbench-preview1`、本地或远程、操作步骤、预期／实际结果、是否稳定复现。可附脱敏截图和“复制界面诊断”的内容。

通过托盘“退出”，按提示确认“结束本地任务并退出”以完整关闭；窗口右上角关闭默认隐藏到托盘。未保存的合并决策会询问处理方式；普通文档按恢复记录保留。再次启动同一候选保留验收配置。已知实现边界见 [兼容参考](../reference/compatibility.md)，本轮检查见 [工作台重构验收](../validation/2026-11-16-workbench-redesign.md)。包内文档保留构建时快照，后续检查记录以仓库为准。
