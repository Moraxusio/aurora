## 本轮修正

1. **区域独立**：上方文档/AI/工具视图，下方终端及会话列表。打开终端不替换文件树；终端不参加文档分屏、拖放和批量关闭。
2. **消除遮挡**：右侧标签、相邻分屏与欢迎页都有明确正文边界和独立裁剪，编辑区与终端面板矩形不重叠。
3. **布局不搬家**：切换预设保留现有组 ID、标签归属、活动项与焦点；新增格子为空，减少时才合并。
4. **隐藏不结束**：固定宿主保留 widget、未保存文本、AI 状态与终端流；隐藏内容保持最后约束。关闭本地视图仍按原规则结束本地会话，远程关闭视图仍保留 tmux。
5. **焦点及异步保护**：两区分别维护活动项；延迟终端连接不抢文档/弹窗焦点；会话刷新/结束检查连接和实例，结束 RPC 失败保留视图。服务异步加载完成后快捷键仍可用。
6. **仅记高度**：沿用旧可选布局字段，仅将面板高度保存到浏览视图 `tabLayout['panel_height']`。不保存会话 ID、面板可见性/最大化、终端输入或未保存正文，不重置/迁移 API Key/OAuth。

## 操作

- `Ctrl+J`：显示/隐藏底部终端；`Ctrl+反引号`：聚焦；`Ctrl+Shift+反引号`：新建。
- `Ctrl+1–4`：回到对应文档视图；`Ctrl+Tab`、`Ctrl+W` 跟随当前焦点区域。
- 拖动终端上缘调整高度，双击复位；面板右上角可最大化/还原、显示列表、隐藏。
- 窄窗临时显示当前焦点区域，返回宽窗不重建原布局。完整文档操作见 [TABS.md](TABS.md)。
