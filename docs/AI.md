# AI 工作台与 ChatGPT 订阅

设备码授权和上下文元数据从 3.12.0 起提供；本文的本机授权、附件传输、目录选择和显示优化属于 **3.13.0**。原始图片/PDF/文件附件需要 3.13.0 客户端及 agent，旧 3.12.0 agent 没有 `ai.attach.*`。

## 后续实现（未发布）：本机开发与工作状态

- Windows 新增[本地 agent](LOCAL_AGENT.md)，与远程 agent 独立。模型请求由当前执行端发出：本地模式从本机，远程模式从服务器；不是把所有开发搬到远程。
- “正在工作”面板显示 shell 命令、增量输出、代理来源、运行中子代理及其内部工具，可打开子会话。活动快照与待批准操作随会话同步，不只靠页面打开后收到的事件。
- 长历史改用 `ai.history` 的分块流，保持 1 MiB 帧上限。超大步骤事件触发同步，不再因单帧过大空断流；单次历史上限 64 MiB。初次失败可重试，已有会话同步失败保留画面和输入。**远程使用这些能力需要同步更新 agent**，旧 3.13.0 服务端仍只有单帧 `ai.get`。
- 提供商设置中可以输入模型 ID 并“添加此模型”，搜索/选择/移除已保存模型；拉取结果与已有模型合并，不丢手动条目。列表惰性构建，避免一次绘制所有模型。
- 拉取可选择“本机网络”或“当前 agent 网络”。API Key 兼容 data/models 对象、数组列表、常见上下文字段与 `has_more/last_id` 分页；对网页、鉴权错误、空列表分别提示；最多 20 页、单页 4 MiB，拒绝重定向。ChatGPT 订阅仍是内置建议，不冒充账号可用性查询。
- 本地终端和 AI shell 继承环境/Windows 手动代理；远程提供商启用代理时，shell 和子代理使用相同执行端代理设置。Windows AI shell 使用 PowerShell 语法及 Job Object 取消进程树，不套用 Unix 只读命令白名单。
- 沿用原加密 profile 格式；API Key 与 OAuth 不清空。设置窗口保存保留后台轮换的新 OAuth/API Key，冲突时拒绝覆盖。切换到订阅不会自动擦除原 API Key，但订阅请求不会使用它。

以下章节描述 3.13.0 的已发布行为；上述改造尚未打包发布，真实账号/真机边界不变。

## 查看提供商、模型和上下文

- 工作台上方显示本步/最近一步实际发送的提供商配置与模型 ID；下方另列下一次调用的选择。运行中切换模型不会改写旧回答的身份。
- 每条回答保留当时的提供商和模型。旧会话没有这些信息时显示“未知提供商”，不会用当前设置猜测。
- 上下文显示活动历史的 **估算 tokens / 输入预算、百分比和占用条**；悬停说明中可查看上次调用的精确输入 tokens。缓存命中已经包含在输入中，不重复相加。
- “累计用量”是所有调用消耗，**不是上下文长度**。压缩与回退后活动上下文重新估算；未发送的输入、附件不在这个统计里。
- 模型目录返回的上下文按模型保存。AI 设置可手动覆盖输入窗口，留空或 0 使用目录/默认预算；此手动覆盖对该提供商配置生效，换模型时应检查并清除旧值。
- 默认预算不保证等于上游的真实最大窗口；网关也可能把模型 ID 映射到别的模型，Aurora 无法认证网关内部实际使用的模型。

## 使用 device 模式连接 OpenAI / ChatGPT

1. 连接服务器并启用 `ai` 服务，打开 AI 设置。
2. 添加“OpenAI / ChatGPT 订阅（设备码）”预设，或将登录方式改成“ChatGPT 订阅 · Device 设备码”。
3. 默认选择“本机网络 / 系统代理”，设备码申请、令牌交换及后续刷新直接从客户端发出。也可在授权页下拉改为“服务器网络 / 服务器代理出口”；此时使用服务器出口及提供商的“代理出口”设置。**模型调用始终从服务器发出**，与授权出口分开。
4. 点“使用设备码登录”，自行在浏览器打开 `https://auth.openai.com/codex/device`，输入对话框中的设备码并批准。账号需要启用设备码登录，并有相应订阅/模型资格。
5. 授权成功后登录凭据立即加密保存；选模型后点“保存并启用”。订阅模型列表只是内置建议，不是账号可用性查询，也可以手动输入模型 ID。

仅授权自己刚刚发起的登录，不要把设备码交给他人。最长等待 15 分钟；取消、返回或到期会停止后续轮询，在途响应也不会继续应用。

获取设备码失败时可以“重新获取设备码”，或切换授权出口后重试。获取设备码阶段的 HTTP 403 不能证明订阅无效；HTML/网页安全验证会单独提示，不显示上游页面正文。切换到本机出口可以避开服务器网络的问题，**不保证解决 OpenAI 对所有网络、区域或账号的限制**。

本机授权优先采用进程环境 HTTP(S) 代理；没有时，Windows 读取当前用户的手动系统 HTTP(S) 代理，Android 使用系统 `ProxySelector`。不读取浏览器 cookie、已有账号文件或代理认证凭据；Windows 的 PAC-only / 自动发现配置目前不解析，必要时请使用手动代理或服务器出口。

**注意：登录和退出立即保存，不受设置窗口底部“取消”影响。** 退出只清除本机令牌；如需撤销账号端授权，请到 OpenAI 的账号设置处理。

## 粘贴及选择图片、文件

- 在 AI 输入框按 **Ctrl+V**，或用输入框菜单“粘贴 / 图片 / 文件”、附件按钮中的“粘贴图片 / 文件 / 文本”。Windows 支持剪贴板 PNG、位图及资源管理器复制的文件；Android 支持系统授权的 content URI、支持该能力的输入法图片插入。只在用户主动粘贴时读取，不监听剪贴板。
- 附件按钮可“选择本机图片 / 文件…”或“浏览服务器文件…”，后者使用根目录下拉、目录列表和面包屑，不用手打路径。普通剪贴板文本即使看起来像路径，也只作为文字粘贴，不自动打开文件。
- 待发送附件显示缩略图/文件名/大小，可逐个移除；**粘贴不会上传，点击发送后才上传**。上传和发送失败保留输入及附件，发送期间显示进度。历史图片可点击放大，UTF-8 文本可查看；PDF 历史卡片只说明已提供原文档，不是 PDF 阅读器。
- 支持 PNG/JPEG/GIF/WebP、PDF、UTF-8 文本/代码；每件 **≤8 MiB**，文本 **≤256 KiB**，每条 **≤8 件、合计 ≤20 MiB**。常见私钥、密钥库和 `profile.bin` 文件名在读取前拦截（Android content URI 依赖提供方给出的文件名）；这不代替用户检查附件内容。
- 图片/PDF 作为原始多模态内容发给模型，不伪装成文本；三个协议都支持对应的附件请求结构，但是否接受仍由模型和网关决定。上下文中的图片/PDF tokens 是粗估，不是 base64 长度或精确消耗。

### 传输与保留

附件使用 `ai.attach.upload/download` 的分块流；1 MiB JSON 帧上限不变，会话、事件与聊天请求只保存附件引用及元数据，原始媒体仅在发给上游时临时转换为 data URL。附件保存在 agent 私有的 `<StateDir>/ai/attachments`（目录 0700、文件 0600），不写工作目录；下载和重放校验 SHA-256，上传中断不提交。聊天附件内容不加密落盘，请把它视为已复制到服务器。

附件库限额为 512 MiB。删除会话时清理该会话关联且不再被其他会话/运行中 inbox 引用的附件；**上传成功但发送未成功、窗口关闭或回退/截断掉历史的附件可能残留，目前没有孤儿附件自动回收**。达到限额会拒绝新上传，不会静默删除仍被引用的数据。

## 工作目录与阅读体验

- 新会话从顶部目录菜单选择项目文件夹、服务器根目录，或“浏览服务器目录…”逐级选择。已有会话目录固定；要换目录请新建会话，避免历史和权限上下文混用。文件服务关闭时无法浏览，仍可沿用已有会话目录。
- 对话正文默认 15 px，使用界面字体及中文回退、较宽松的行距；代码保持等宽。顶部字号菜单提供 13.5 / 15 / 17，偏好保存在本机加密配置中。回答支持一键复制。
- 历史消息惰性构建并缓存，流式文本约 33 ms 合帧更新；向上读历史时不强制滚底，可点“回到最新消息”。中文输入法仍在组词时 Enter 不发送，Shift+Enter 换行。

## 凭据与实现范围

- API Key、OAuth access/refresh 都只保存在客户端加密 `profile.bin`（Windows DPAPI / Android Keystore 保护的加密配置）。
- run/models/compact 仅经固定指纹 TLS 发送 access；本机授权的 refresh 不发给 agent，仅“服务器网络”方式在专用刷新 RPC 中短暂经过 agent 内存。授权出口随凭据加密保存，旧凭据缺失出口字段时默认本机。令牌不进入 agent 会话文件、广播事件或审计记录。
- 客户端在发送、取模型、压缩前检查到期并合并并发刷新；先成功保存新令牌，再使用它。保存失败保留输入，不继续发送。
- 订阅固定连接官方 ChatGPT/Codex，忽略自定义地址与 headers，拒绝重定向；不会把订阅令牌交给普通 API 网关。
- 长任务超过 access 有效期时会报错；回到客户端重新发送即可触发刷新，必要时重新登录。agent 不保存 refresh 来无限续跑。
- 复用 OpenCode MIT 的 headless device 流、token 交换/刷新、account 路由、Codex HTTP SSE 与默认订阅输入预算；标题、压缩和子智能体共用这一路径。ChatGPT Responses 的大于 512 KiB 请求使用 zstd（沿用已有 BSD 依赖 `klauspost/compress`）。尚未移植 WebSocket、browser callback 或 token-sharing。
- 自动化验证使用本地 HTTP 桩、合成令牌和文件、无真实窗口的 Flutter 组件截图；**真实订阅账号授权/多轮对话、Windows 原生剪贴板交互和 Android 真机粘贴仍未验证**。编译通过不等于实机验收。
