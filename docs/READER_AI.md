# PDF 阅读与 AI 工作导航（Windows 3.20.0）

## PDF

- 鼠标默认选字；`V` 选择、`H` 手形拖动，按住空格临时拖动。松开、失焦或隐藏阅读器后恢复原模式。
- 滚轮滚动，`Ctrl+滚轮` 围绕指针缩放；触屏单指拖动、双指缩放、长按选字；触控板独立识别。
- 阅读选项加入封面独立的双页布局、当前页标记；`Ctrl+D` 标记，`Alt+←/→` 返回／前进阅读位置。
- 搜索支持区分大小写和 Unicode 全词匹配；保留目录、缩略图、页码跳转、缩放、夜间模式和下载。
- 窄窗目录覆盖阅读区，选择章节或标记后收起。位置／缩放／双页／标记按服务器、根目录、路径和文件版本隔离，最多记忆 64 份文档，仅本次客户端会话有效。
- PDF 范围读取绑定到打开代次及 reader 身份；隐藏时暂停搜索与页面渲染。双页几何缓存随文档事件失效。

## AI

- 顶部固定工作切换栏：主对话、子代理、Shell；右端“所有工作”支持搜索运行中和已完成的任务。
- 子代理在当前 AI 面板内切换；主／子对话分别保留草稿、附件、阅读锚点和流连接。从历史直接打开子会话时，顶部提供返回上级代理入口。
- Shell 输出有独立可选文本视图、复制和“回到最新输出”；向上阅读时停止跟随。输出按稳定行锚点布局，后台暂停绘制。
- 任务完成后保留入口和结果。历史跨消息配对工具调用／结果；断流重新同步活动快照，补查已知子会话的任务历史。未取得完成结果的活动显示“未确认”。
- 工作缓存保留最近 120 项及运行中／已打开任务；超出的旧结果仍可从原消息打开。每项增量输出限制为最近 4096 行／256K 字符窗口，最终结果以 agent 工具记录为准。
- 对话、工具卡片、输入框、历史、模型选择、提供商设置共用中性色面板、6px 圆角、图标及状态表达。设置按连接、身份、模型划分区域。
