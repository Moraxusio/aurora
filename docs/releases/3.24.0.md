# 3.24.0：AI 控制、工作台重构与非 AI 可靠性修复

> 类型：版本说明 | 状态：生效 | 维护：项目维护者 | 更新：2026-11-18
> 适用：Windows x64 正式客户端、Windows 本地 agent、Linux amd64 agent

## 下载与升级

[GitHub Release](https://github.com/Moraxusio/aurora/releases/tag/v3.24.0) 提供完整 Windows ZIP、ZIP SHA-256 sidecar 和 `SHA256SUMS.txt`。

完整解压 `Aurora-3.24.0.zip` 后运行 **`aurora.exe`**。正式版使用当前 Windows 用户的正常 Aurora 配置；此前候选包的 `review-data` 为独立验收配置。本地 agent 已随包提供；远程开发需要匹配的 3.24.0 agent，由客户端提示、用户选择升级。

## 主要成果

### AI 配置中心与运行控制

- 统一对话、任务与设置入口；输入区集中模型、本次发送、附件、发送快捷键与发送／停止控制。
- 新增项目预算、快照、指令、技能、MCP 与模型价格表单，高级 JSON 保留同一草稿，明确配置范围与继承关系。
- 预算支持逐项不限、已用／预留／费用／下一步需求展示及中断恢复；逐消息可继承／开关／自定义预算，补充指令共享当前预算，排队项固定接收时配置。
- 子代理并发 1–16、总量上限、禁用与只读策略由服务端强制执行，禁止递归派生；工具调用上限、重复确认与 Shell 超时可配置。
- 快照使用真实 Git 忽略规则排除嵌套未跟踪依赖与大型新文件，修复阈值与重复内容存储问题；继续保留 OpenCode 兼容协议及 `User-Agent`、`originator`、`x-opencode-client` 标识。

### 工作台 GUI 重构

- 68px 常显文字导航、统一面板标题、任务卡首页与本机开发入口；键盘可激活全部主要入口，窄窗底栏常显标签。
- 按服务器独立保活侧栏与工具页；重连、主题和缩放切换保留搜索条件、提交草稿、筛选与阅读位置。
- Git 提供文字化拉取／推送、分仓库草稿及按需构建更改列表；搜索、服务、端口、代理改用自适应窄窗布局。
- 桌面 150% 缩放保留编辑器与底部终端显示空间；文件工具栏在窄侧栏与触控模式下自动换行并保留打开中的菜单实例。

### 非 AI 执行逻辑与可靠性

- 连接请求合并、连接代次与本地 agent 所有权、升级查询旧回执隔离；端口转发串行化、迟到监听回收与持久化失败回滚。
- Git 写操作单飞、确认目标绑定、旧回执隔离与退出前未保存合并决策保护；跨根移动部分成功报告、剪贴板与变脏标签保护。
- 非完整搜索拒绝替换预览；终端重连／UTF-8 状态隔离、并发关闭合并、正常关闭与重置区分及 Windows 退出输出排空。
- 代理连接租约与测速取消；systemd 同服务并发互斥、隐藏暂停轮询、阅读期间缓存；任务取消拒收迟到完成、调试单飞与监控重连保活。
