# Aurora 3.21.4 AI harness 与界面收敛

## 工具与执行链

- `read` 在当前执行主机读取 PNG/JPEG/GIF/WebP/PDF，直接作为模型输入。读取时捕获不可变附件；历史和事件只存引用，请求发送时再载入字节。
- Chat/Responses 在整批工具结果之后发送带来源标记的媒体；Anthropic 将媒体嵌入 `tool_result.content`。切换到禁用媒体的模型时，历史给出明确省略说明，新附件在接收前拒绝。
- 全局默认与逐模型覆盖统一解析；工具声明和执行使用同一能力表。关闭工具后，即使模型请求调用也不会执行。
- `apply_patch` 支持新增、精确更新、删除和移动。先预校验全部目标，再逐文件批准；写入前重新检查路径、原文和文件模式。提交失败恢复已改动文件。普通 `write`/`edit` 使用相同重验和提交锁。
- 必填参数和参数类型在执行前校验；省略 `content` 不再可能被解释为清空文件。文件写入使用临时文件、同步和重命名，失败不会退回非原子覆盖。
- `grep` 支持字面文本、大小写、隐藏文件和结果上限；逐文件遵守内容读取规则，遍历和输出有界。`glob` 支持结果上限，取消不会被误报为“无匹配”。
- `question` 提供单选、多选、自定义答案、跳过与停止取消；连接恢复可重新取得待答问题，重复提交不会重复投递。子代理不声明这个交互工具。
- 执行前持久化工具调用，每个工具结果单独检查点。保存失败停止后续执行；重启只为缺失结果补充“结果未知，需要检查实际状态”，不自动重放副作用。恢复按工具批次匹配，防止上游重复调用 ID 混淆结果。
- 每步最多执行 64 个工具调用；单任务步骤上限会给出明确状态。停止后未执行的调用补齐取消结果。

## 配置语义

能力顺序：内置默认 → 旧模型目录信息 → 显式全局默认 → 逐模型覆盖。
能力键：`tool_calling,image_input,pdf_input,read,glob,grep,write,edit,apply_patch,shell,webfetch,websearch,todowrite,subagent,question`。

每次输入接收时冻结模型、能力、思考配置和权限；排队项保留各自的快照。
客户端通过 `ai.capabilities` 检测新 harness；旧 agent 不得静默忽略显式能力设置。

- 思考强度允许填写 `high`、`max`、`xhigh` 等值。
- 模型思考预设为 `null` 时继承连接；空字符串表示省略参数；会话临时覆盖优先。
- 档位映射如 `max=ultra, off=`：`max` 发 `ultra`，`off` 不发；未映射自定义值原样发送。
- OpenAI Chat/Responses 透传自定义 effort。Anthropic 可选协议默认、自适应 effort 或显式 Token 预算；未知值不会悄悄降成默认预算。

参考 DeepSeek Harness 实际源码提交 `39163dd30f703a79079e2d2446545cff3c453738` 的
`llm-pi-ai/src/config.ts` 与 `catalog.ts` 能力/思考映射语义。
保留原 OpenCode 兼容协议和 `User-Agent`、`originator`、`x-opencode-client` 标识。

## 界面约定

1. 设置收敛为「连接」「模型」「工具与权限」「对话」四页；网络出口收进连接页，次要工具清单按需展开。
2. 单击模型查看配置，星标明确设为默认。查看另一个模型不会切换默认模型。
3. 会话模型选择器先选模型和思考强度，最后「应用」；关闭取消。内容滚动，应用按钮固定，短窗口仍可操作。
4. 会话菜单、快捷命令、宽窄布局按钮统一动作路由；同一输入组件处理 Enter、输入法合成和图片/文件粘贴。
5. 上下文详情按需弹出并实时更新，不持续占用对话高度。常用发送、停止、模型选择保留短路径。
6. 问题待答时显示入口；提交中禁止重复点击，失败保留选择与文字。工具卡片展开后才加载媒体预览，PDF 使用实际阅读器。
7. 保活面板使用同生命周期的局部浮层与独立语义边界：隐藏面板时，提示气泡和选择控件也退出绘制与原生语义树，避免暂停动画后根浮层遗留孤立节点或重复挂接；文档状态、焦点隔离和完整无障碍能力继续保留。
