# Aurora 3.25.0-gui-preview11

> 类型：版本说明 | 状态：候选 | 维护：客户端维护者 | 更新：2026-11-20
> 适用：Windows x64 签名验收候选及随包 agent

## 桌面体验改动

- 顶部统一进入文件名、文件内容和命令搜索；侧栏集中显示内容结果及其选项。
- 未打开文档时，让 AI 和终端使用空出的编辑区。重新打开文档时恢复分栏；拖动右侧分隔线会重排中央编辑器内容。
- 文件树和内容搜索结果支持预览标签。单击复用预览，双击或开始修改保留标签；未修改的预览不进入重启恢复列表。
- 编辑器路径和常用操作同排，低频操作集中到 `…`。AI 空白页与历史列表减少重复控件，示例只填入草稿，不自动发送。

## 验收建议

1. 打开文件树和 AI，写一条未发送草稿。关掉所有文档后确认左右相邻，再打开长行文件，拖宽右栏确认中央重排且 AI 草稿仍在。
2. 连续单击两个文件，确认仅保留最后一个斜体标签。双击保留该文件，再单击另一文件并编辑，确认两个标签都保留。
3. 从顶部切换到内容搜索，使用 `Ctrl+Shift+F` 返回输入框，并用 `Ctrl+P` 按文件名打开。切换侧栏后返回，检查关键词仍在。

启动、快捷键和恢复规则参见 [开始使用](../guides/getting-started.md)。此候选只用于本地验收，不是公开发布。
